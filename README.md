# WashNearMe — Car Wash Booking Prototype

High-fidelity interactive UI prototype for **WashNearMe**, an automotive detailing and car wash booking application serving **560037, Bengaluru, Karnataka, India**.

## 🚀 Overview

- **Service Area**: 560037, Bengaluru (Brookefield, AECS Layout, Kundalahalli)
- **Supported Vehicles**: 4-wheelers (Hatchback / Compact, Sedan, Compact SUV, SUV)
- **Services Offered**: Interior Cleaning, Body Wash, Underbody Cleaning
- **Slot Model**: Dedicated 30-minute booking intervals, up to 7 days in advance
- **User Journeys**: Customer Booking Experience & Car Wash Partner Portal

## 📱 Prototype Screens Included

1. **Screen 1 — Landing / Home**: Hero section, service cards, why choose us.
2. **Screen 2 — Car Wash Listing**: Filterable directory of 5 demo detailing centers.
3. **Screen 3 — Car Wash Details**: Photos, ratings, services, customer testimonials.
4. **Screen 4 — Booking Selection**: 4-step progressive flow (Service → Vehicle → Date → Time).
5. **Screen 5 — Booking Summary**: Itemized pricing, vehicle specs, and confirmation CTA.
6. **Screen 6 — Booking Confirmation**: Success badge, booking ID, bay arrival notice.
7. **Screen 7 — My Bookings**: Segmented tabs for Upcoming and Past reservations.
8. **Screen 8 — Customer Profile**: Account details and quick shortcuts.
9. **Screen 9 — Partner Login**: Fast 1-click demo login for car wash owners.
10. **Screen 10 — Owner Dashboard**: Live metrics and 30-minute slot timeline schedule.
11. **Screen 11 — Owner Bookings**: Operational list of Today's, Upcoming, and Completed jobs.

## 🛠️ Tech Stack

- **HTML5 & CSS3**: Vanilla CSS with custom automotive design system.
- **JavaScript (ES6+)**: Client-side state machine and interactive mock data engine.
- **Typography**: Google Fonts (Outfit & Plus Jakarta Sans).
- **Responsive**: 390px mobile viewport simulation with one-click desktop expansion.

## 💻 Getting Started

Simply open `index.html` in any modern web browser or serve locally using any static web server.
